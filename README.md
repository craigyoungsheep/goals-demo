# frame.work demo

A shareable interactive demo with fictional goals and work.

- [Try onboarding](https://craigyoungsheep.github.io/goals-demo/?onboarding=preview)
- [Explore the sample workspace](https://craigyoungsheep.github.io/goals-demo/)

Six curated work examples connect research, delivery, collaboration and coaching to the sample goals. **Sample update** opens a manager-ready draft with links to fictional evidence pages; review before copying. Applied references are grouped with one short explanation, with individual evidence available in Details. These are editorial fixtures, not live AI output. Existing tabs can use **Reset demo** to load the new examples.

Use fictional information only. Onboarding preview responses disappear when you leave. Workspace changes stay in each visitor’s browser tab. AI connections and reminders are disabled. Reset demo restores the fictional workspace.

This repository contains generated static files only. The hosted Supabase application, credentials and local records are not included.
